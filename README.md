# roca

Sistema da roça (Fazenda Buritis): rebanho leiteiro, reprodução, remédios, controle leiteiro/boost, folha do leite com parceiros e fluxo de caixa.

- Site: https://guisilva301.github.io/roca/
- Um único `index.html` (HTML, CSS e JavaScript puros) + `sw.js` (abre sem internet).
- Dados no Firebase (projeto `fazenda-buritis`, Firestore em São Paulo). Só e-mails liberados nas regras do Firestore conseguem ler e gravar.
